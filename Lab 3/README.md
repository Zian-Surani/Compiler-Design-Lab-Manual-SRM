# Lab 3 – NFA to DFA Conversion

## Objective

To convert an **NFA into an equivalent DFA** using the **subset construction algorithm**.

## Features

* Computes **ε-closure**
* Implements **move function**
* Generates **DFA states from NFA state sets**
* Identifies **final states**
* Displays **DFA transition table**

## Concepts Used

* Deterministic finite automata
* Power-set construction
* Closure operations

## How to Run

```bash
gcc lab3.c -o lab3
./lab3
```
