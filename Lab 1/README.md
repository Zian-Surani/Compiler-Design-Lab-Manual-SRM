# Lab 1 – Lexical Analyzer

## Objective

To implement a **lexical analyzer in C** that scans a C source file and converts the input stream into **tokens**.

## Features

* Detects **keywords, identifiers, numbers**
* Recognizes **operators, delimiters, and string literals**
* Removes **single-line and multi-line comments**
* Builds a **symbol table**
* Displays **line-wise token output** for learning

## Concepts Used

* Tokenization
* Implicit **DFA-based scanning**
* Symbol table management

## How to Run

```bash
gcc lab1.c -o lab1
./lab1
```
