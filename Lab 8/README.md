# Lab 8 – Shift Reduce Parser

## Objective

To implement a **basic shift-reduce parser** demonstrating **bottom-up parsing**.

## Features

* Explicit **shift** and **reduce** operations
* Stack-based handle detection
* Parsing trace visualization
* String acceptance verification

## Concepts Used

* Bottom-up parsing
* Handle pruning
* Reduction strategy

## How to Run

```bash
gcc lab8.c -o lab8
./lab8
```
