# Lab 9 – Operator Precedence Parser

## Objective

To construct and simulate an **operator precedence parser** for arithmetic expressions.

## Features

* Operator precedence table construction
* Relation handling: `<`, `=`, `>`
* Deterministic shift-reduce decisions
* Expression validation

## Concepts Used

* Operator grammars
* Precedence parsing
* Deterministic bottom-up parsing

## How to Run

```bash
gcc lab9.c -o lab9
./lab9
```
