# Lab 2 – Regular Expression to NFA

## Objective

To construct an **NFA from a regular expression** using **Thompson’s Construction**.

## Features

* Converts **infix → postfix** regular expression
* Supports operators: `|` (union), `.` (concatenation), `*` (Kleene star)
* Uses **linked list transitions**
* Prints **formal NFA transition table**

## Concepts Used

* Regular expressions
* ε-transitions
* Automata construction

## How to Run

```bash
gcc lab2.c -o lab2
./lab2
```
