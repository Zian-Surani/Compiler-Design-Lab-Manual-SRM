# Lab 12 – LALR(1) Parser

## Objective

To construct an **LALR(1) parser** by merging compatible **LR(1) states**.

## Features

* State merging from LR(1) automaton
* Conflict preservation checking
* Reduced parsing table size
* Practical compiler-level parsing

## Concepts Used

* LALR parsing
* State equivalence
* Efficient bottom-up parsing

## How to Run

```bash
gcc lab12.c -o lab12
./lab12
```
