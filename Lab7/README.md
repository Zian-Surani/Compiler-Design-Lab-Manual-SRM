# Lab 7 – Predictive Parsing (LL(1) Parser)

## Objective

To implement a **predictive parser** using the **LL(1) parsing table** for validating input strings.

## Features

* Stack-based parsing mechanism
* Input buffer simulation
* Step-by-step derivation tracing
* Accept / reject decision output

## Concepts Used

* LL(1) parsing
* Top-down parsing strategy
* Parsing table driven control

## How to Run

```bash
gcc lab7.c -o lab7
./lab7
```
