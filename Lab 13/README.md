# Lab 13 – Intermediate Code Generation

## Objective

To generate **three-address code (TAC)** for arithmetic expressions.

## Features

* Temporary variable creation
* Quadruple / triple representation
* Expression tree translation
* Structured intermediate representation

## Concepts Used

* Syntax-directed translation
* Intermediate representation design
* Compiler front-end to middle-end bridge

## How to Run

```bash
gcc lab13.c -o lab13
./lab13
```
