# Lab 4 – Left Recursion Removal & Left Factoring

## Objective

To transform a **context-free grammar** by removing **left recursion** and applying **left factoring**.

## Features

* Eliminates **immediate left recursion**
* Introduces **new non-terminals (A′)**
* Handles **ε-productions**
* Performs **common prefix factoring**
* Shows **step-by-step grammar transformation**

## Concepts Used

* Grammar normalization
* Preparation for **predictive parsing**

## How to Run

```bash
gcc lab4.c -o lab4
./lab4
```
