# Lab 10 – SLR(1) Parsing Table Construction

## Objective

To build an **SLR(1) parsing table** for a context-free grammar.

## Features

* LR(0) item generation
* Closure and GOTO computation
* ACTION and GOTO table creation
* Conflict identification

## Concepts Used

* SLR parsing
* Canonical LR(0) automaton
* Bottom-up deterministic parsing

## How to Run

```bash
gcc lab10.c -o lab10
./lab10
```
